# Institution portal overview

Use this section when you work for a recognized institution. You only see and change **your institution’s** students and issuance activity.

## Sidebar map

| Sidebar | Guide page |
|---|---|
| Dashboard | Shared [Getting started](../getting-started.md); institution users land on Dashboard then open the portal |
| Institutions → Institution portal | [Portal home](portal-home.md) |
| Institutions → Students | [Students](students.md) |
| (from Students) Import | [Import students](student-import.md) |
| (from Students) Student detail / Issue | [Student detail and Issue NSID](student-detail-issue.md) |
| Settings | [Settings](settings.md) |

MoE **Manage institutions** and national NSID admin menus are not shown to institution-only accounts.

## Typical workflows

1. **Import or add students** to your roster (student number unique within your school).
2. Open a student → **Issue NSID** → complete Fayda → generate or **Approve & link** when names differ but you confirm the match.
3. **Export CSV** for reporting (with or without NSID, date filters).

## Scope reminder

Roster rows belong to one institution. Another school cannot see your students, even if the same person later holds an NSID linked to multiple institutions.
