# Roles

## Purpose

Browse defined roles and their permissions. This screen is informational for operators who assign access via invites and user forms.

## Who sees it

Users with `user:read`.

## How to open

Sidebar → **User Management** → **Roles** (`/roles`).

> Screenshot placeholder: `admin-roles.png` — capture from the live console and save to `assets/screenshots/admin-roles.png`.


## Actions

1. **Search / filter** roles.
2. **Reload** the list.
3. Review role names and permissions. Creating custom roles in the UI is not part of the current operator flow (read-only list).
