# Access sessions

## Purpose

Review student portal OTP / profile access sessions (masked phone, status, expiry). Token hashes are not shown.

## Who sees it

Users with `fsid:read`.

## How to open

Sidebar → **NSID** → **Access sessions** (`/access-sessions`).

> Screenshot placeholder: `admin-access-sessions.png` — capture from the live console and save to `assets/screenshots/admin-access-sessions.png`.


## Actions

1. Browse or reload the list.
2. Use the list for support investigation (session status and timing). There is no staff “approve access” action on this page — it is read-only.
