# Audit

## Purpose

Search FSID audit events (requested, verified, issued, institution actions, and related types) for compliance and troubleshooting.

## Who sees it

Users with `fsid:read`.

## How to open

Sidebar → **FSID** → **Audit** (`/audit-events`).

> Screenshot placeholder: `admin-audit.png` — capture from the live console and save to `assets/screenshots/admin-audit.png`.


## Actions

1. **Search / filter** events when filters are available.
2. **Reload** to refresh.
3. Read event type, related session or FSID, detail text, and timestamp. The table is read-only.
