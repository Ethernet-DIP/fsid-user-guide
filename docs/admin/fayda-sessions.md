# Fayda sessions

## Purpose

Monitor staff and portal Fayda verification / issuance sessions (status, provider transaction, verified fields, outcome).

## Who sees it

Users with `fsid:read`. Cancelling a session requires `fsid:issue`.

## How to open

Sidebar → **FSID** → **Fayda sessions** (`/issuance-sessions`).

> Screenshot placeholder: `admin-fayda-sessions.png` — capture from the live console and save to `assets/screenshots/admin-fayda-sessions.png`.


## Actions

1. Filter or search by status when available.
2. **Reload** the list.
3. Open a session to view detail (status, consent, provider, verified identity, issued FSID).
4. On a non-issued session, use **Cancel session** (if you have issue permission) to stop an abandoned flow.
