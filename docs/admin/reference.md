# Reference

## Purpose

Maintain national lookup tables used by the system (for example nationalities). This is MoE reference data administration, not end-user help content.

## Who sees it

All authenticated users can open Reference; create/edit/delete actions depend on backend permissions for reference management.

## How to open

Sidebar → **Reference** (`/references`, redirects to a default key such as nationalities).

> Screenshot placeholder: `admin-reference.png` — capture from the live console and save to `assets/screenshots/admin-reference.png`.


## Actions

1. Select a reference category from the page navigation.
2. **Add** a new entry.
3. **Edit** an existing row.
4. **Delete** or toggle **active** when those controls are shown.
